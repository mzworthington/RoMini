# 0008. PN532 host bus is I2C

Superseded by [0009](./0009-pn532-spi.md).

## Context and Problem Statement

[ADR-0005](./0005-pn532-spi-analogue-audio.md) chose Waveshare PN532 **SPI** (cs=4, reset=20) because the vendor warns that Raspberry Pi I2C lacks clock stretching. On the live box, SPI firmware detect stays silent with clean GPIO (no pin hog). The HAT is now used on **I2C**.

## Decision Outcome

PN532 over **I2C-1** (address `0x24`), reset BCM 20. Composition: `romini.composition.pn532_hat.PN532_I2C`. Enable `dtparam=i2c_arm=on`. Analogue PWM audio from ADR-0005 is unchanged.

Jumpers latch at 5V: I0 **H**, I1 **L**. DIP **SCL SDA ON**; SCK/MISO/MOSI/NSS and RX/TX **OFF**. SPI DIP ON with I2C software does not connect SDA/SCL.

## Consequences

* Good, because the host path matches a bus the HAT can be jumpered onto without CE0/GPIO4 NSS.
* Bad, because Pi I2C clock-stretching can still stall; if the bus locks, recover with a power cycle and treat UART or a different reader as the next hardware option.
