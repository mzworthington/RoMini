# 0009. PN532 host bus is SPI

## Context and Problem Statement

[ADR-0008](./0008-pn532-i2c.md) put the Waveshare PN532 on I2C-1 (`0x24`). On the live box the chip never ACKs `0x24` while the UPS HAT still appears at `0x2d`/`0x43`. The HAT is jumpered for SPI (I0 L, I1 H; SCK/MISO/MOSI/NSS ON).

## Decision Outcome

PN532 over **SPI0**, chip-select BCM **4**, reset BCM **20**. Composition: `romini.composition.pn532_hat.PN532_SPI`. Enable `dtparam=spi=on`. I2C stays on for the UPS HAT only.

Jumpers latch at 5V: I0 **L**, I1 **H**. DIP **SCK MISO MOSI NSS ON**; SCL/SDA and RX/TX **OFF**.

## Consequences

* Good, because the host path matches the HAT mode that does not share SDA/SCL with the UPS.
* Bad, because NSS uses BCM 4; keep other SPI devices off CE0.
